## 📂 Project Categories

Projects are organized according to the primary data analytics tools used:

* **Excel**
* **SQL**
* **Power BI**
* **Python**
* **Tableau**

## 🛠️ Tools & Technologies

Depending on the project, I may use a combination of data analytics and supporting tools, including:

* **Microsoft Excel** — data cleaning, analysis, formulas, pivot tables, and dashboards
* **SQL** — data querying, transformation, and analysis
* **Power BI** — data modeling, visualization, and interactive dashboards
* **Python** — data analysis, automation, and visualization
* **Tableau** — data visualization and dashboard development
* **Microsoft PowerPoint** — presenting findings, insights, and project results
* **Microsoft Word** — project documentation, reports, and supporting analysis

Not every project will use every tool. The tools used will depend on the requirements and purpose of each project.
